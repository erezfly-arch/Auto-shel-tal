# האוטו של טל

אפליקציית Web מותאמת לאייפון (PWA), בעברית ובכיווניות RTL.

## התקנה באייפון
1. פותחים את כתובת האתר ב-Safari באייפון.
2. לוחצים על כפתור השיתוף.
3. בוחרים "הוספה למסך הבית".
4. מאשרים. האפליקציה תיפתח בחלון עצמאי.

## קבצים
- `index.html` — ממשק, עיצוב והתנהגות.
- `manifest.webmanifest` — הגדרות PWA.
- `sw.js` — שמירת מעטפת האפליקציה לשימוש חוזר ולא מקוון.
- `icon.svg` — סמל האפליקציה.

## מגבלות
זו אפליקציית Web שניתן להתקין במסך הבית של iPhone. היא אינה אפליקציית iOS מקורית מחנות App Store ואינה אפליקציית CarPlay. תמיכה אמיתית ב-CarPlay דורשת פרויקט iOS מקורי, יכולות CarPlay מאושרות על ידי Apple, חתימה והפצה דרך Apple.
